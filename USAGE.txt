# Quick Start Guide

This project is now managed via a single interactive command.

### 1. Run the Setup
Open PowerShell in the project root and run:
```powershell
powershell ./setup.ps1
```

### 2. Follow the Prompts
- Provide Azure resource names.
- Provide your country code (e.g., TR).
- Set your dashboard passwords.
- Confirm deployment when asked.

### 3. Cleanup
To delete all resources from Azure:
```powershell
powershell automation/azure_destroy.ps1
```

---
**Advanced Commands:**
- Check Requirements: `powershell automation/check_requirements.ps1`
- Verify Status: `powershell automation/verify_deployment.ps1`
- Manual HTTPS Setup: `powershell automation/configure_https.ps1`
